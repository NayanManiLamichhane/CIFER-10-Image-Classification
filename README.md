# CIFAR-10 Image Classifier

A deep learning project that classifies images into 10 categories using **TensorFlow, Keras, and ResNet50**. It includes a Streamlit web app for uploading images and viewing predictions.

## Features
- Classifies images into 10 CIFAR-10 categories.
- Interactive web interface built with Streamlit.
- Jupyter Notebook documenting model development.

## Technologies
- Python
- TensorFlow & Keras
- NumPy
- Streamlit
- Jupyter Notebook

## Run Locally

1. Clone the repository:
   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Run the application:
   ```bash
   streamlit run streamlit_app.py
   ```

## CIFAR-10 Classes
Airplane, Automobile, Bird, Cat, Deer, Dog, Frog, Horse, Ship, and Truck.
